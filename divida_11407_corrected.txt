## Introdução

Este documento apresenta gráficos animados da série 11407 (Dívida Externa/PIB %) do Banco Central do Brasil, destacando períodos econômicos relevantes:

- **Crise Global (2008-2009)**: Aumento da dívida devido à desvalorização do real.
- **Recessão Brasileira (2014-2016)**: Pico de endividamento pela contração do PIB.
- **Recuperação Pós-Pandemia (2021-2022)**: Estabilização com crescimento econômico.

Os gráficos são interativos, com animações por trimestre, tooltips, e controles de zoom/pausa.

## Configuração e Carregamento de Dados

Carrega pacotes, obtém a série 11407, e verifica os dados.

```r
#| label: setup
#| echo: false

# Carregar bibliotecas
library(rbcb)
library(dplyr)
library(lubridate)
library(plotly)
library(htmlwidgets)

# Função para obter e processar dados
get_and_process_data <- function(series_code, series_name = "Dívida Externa / PIB (%)") {
  data <- tryCatch({
    get_series(series_code, as = "data.frame")
  }, error = function(e) {
    cat("Erro ao obter dados da série ", series_code, ": ", e$message, "\n")
    return(NULL)
  })
  
  if (is.null(data) || nrow(data) == 0) {
    cat("Nenhum dado obtido para a série ", series_code, "\n")
    return(NULL)
  }
  
  value_col <- names(data)[names(data) != "date"]
  if (length(value_col) != 1) {
    stop("Coluna de valor inválida para a série ", series_code)
  }
  
  data <- data %>%
    rename(date = date, valor = !!sym(value_col)) %>%
    mutate(
      date = as.Date(date),
      valor = as.numeric(valor),
      indicador = series_name,
      trimestre = paste0(year(date), "Q", quarter(date)),
      tooltip = paste(
        "Data:", format(date, "%Y-%m-%d"),
        "<br>Valor: ", sprintf("%.2f%%", valor),
        "<br>Trimestre: ", trimestre)
      )
    ) %>%
    filter(!is.na(valor) & !is.na(date)) %>%
    arrange(date)
  
  return(data)
}

# Obter dados da série 11407
divida <- get_and_process_data(11407, "Dívida Externa / PIB (%)")
if (is.null(divida) || nrow(divida) == 0) {
  stop("Não foi possível obter dados da série 11407")
}

# Depuração: Exibir informações sobre os dados
cat("Número de linhas: ", nrow(divida), "\n")
cat("Período: ", format(min(divida$date, na.rm = TRUE)), " a ", format(max(divida$date, na.rm = TRUE)), "\n")
cat("Primeiras linhas:\n")
print(head(divida, 5))

# Identificar pontos máximo e mínimo
max_point <- divida %>% slice_max(valor, n = 1)
min_point <- divida %>% slice_min(valor, n = 1)
```

## 2.1. Gráfico de Bolhas Animado

Exibe um gráfico de bolhas com tamanhos proporcionais à Dívida Externa/PIB, animado por trimestre.

```r
#| label: graficodadosempainel
#| fig-cap: "Gráfico de Bolhas Animado"
#| warning: false
#| echo: false

p_bubble <- ggplot_ly(
  data = divida,
  x = ~date,
  y = ~valor,
  type = "scatter",
  mode = "markers+lines",
  frame = ~trimestre,
  marker = list(
    size = ~valor / max(divida$valor, na.rm = TRUE) * 30,
    color = ~valor,
    colorscale = list(list(0, "#ff4500"), list(1, "#ff1493")),
    showscale = TRUE,
    line = list(color = "black", width = 1)
  ),
  line = list(color = "#ff4500", width = 2),
  text = ~tooltip,
  hoverinfo = "text",
  hoverlabel = list(bgcolor = "rgba(255,255,255,255,255, 255,255,0.9)", font = list(size = 12))
) %>%
  layout(
    title = list(text = "Gráfico de Bolhas: Dívida Externa de / PIB (%)"),
    common_layout
  ) %>%
  animation_opts(frame = 1000, transition = 600, redraw = TRUE) %>%
  animation_slider(currentvalue = list(prefix = "Trimestre: ", font = list(size = 12))) %>%
  animation_button(x = 0.1, y = 0, label = "Play/Pause")
htmlwidgets::saveWidget(p_bubble, "bubble_divida.html")
p_bubble
```
